# EDUTUTOR-AI
🚀 EduTutor AI

EduTutor AI is a personalized learning platform powered by Generative AI and LMS integration. It delivers real-time academic Q&A, AI-generated quizzes, instant feedback, and performance tracking — seamlessly integrated with Google Classroom.

🧠 Tech Stack

IBM WatsonX + Granite Foundation Models

Pinecone (Semantic Search)

LangChain (Conversational Memory)

Flask Backend with Token-Based Authentication

Secure .env API Key Management

✨ Key Features

Real-time AI tutoring

Adaptive quiz generation

Context-aware responses

Google Classroom integration

Modular & scalable architecture

EduTutor AI makes personalized education smarter, faster, and more accessible.
